# EXAMEN DE PROGRAMACIÓN - TEMAS 0, 1 Y 2
## SECCIÓN: "¿Qué imprime esto?" (Predicting Output)

**PREGUNTAS DE TEMAS 0 Y 1 (Variables, Tipos y Expresiones)**

1.  
   x = 5
   print(f"El valor es: {x}")

   ¿Qué se imprime?
   a) El valor es: 5
   b) El valor es: x
   c) Error de sintaxis

   **Respuesta correcta: a**

2.  
   nombre = "Ana"
   edad = 18
   print(f"{nombre} tiene {edad} años")

   ¿Qué se imprime?
   a) Ana tiene 18 años
   b) ana tiene 18 año
   c) Error por tipo de dato

   **Respuesta correcta: a**

3.  
   temperatura = 25.5
   print(temperatura + 5)

   ¿Qué se imprime?
   a) 30
   b) 30.5
   c) Temperatura25.5 + 5

   **Respuesta correcta: b**

4.  
   x = True
   y = False
   print(f"x es {x} y y es {y}")

   ¿Qué se imprime?
   a) x es True y y es False
   b) x es verdadero y y es falso
   c) Error de tipo booleano

   **Respuesta correcta: a**

5.  
   texto = "Hola"
   print(texto * 3)

   ¿Qué se imprime?
   a) HolaHolaHola
   b) HolaHola
   c) Error de multiplicación con cadenas

   **Respuesta correcta: a**

6.  
   a = 10

   ¿Qué se imprime en orden?
   a) 5.0 y 5
   b) 5 y 5.0
   c) Error de división por cero

   **Respuesta correcta: a**

7.  
   precio = 19.99
   descuento = 10
   print(f"El precio final es {precio - descuento}")

   ¿Qué se imprime (redondeando a 2 decimales)?
   a) El precio final es 9.989999...
   b) El precio final es 9.99

   **Respuesta correcta: b** (El resultado es 9.99).

11.  
    x = 5
    if x > 3:
        print("Más que tres")
    else:
        print("Menos o igual a tres")

    ¿Qué se imprime?
    a) Más que tres
    b) Menos o igual a tres
    c) Nada (no imprime nada)
    d) Error

    **Respuesta correcta: a**

12.  
    nota = 7.0
    if nota >= 5:
        print("APROBADO")
    elif nota == 9:
        print("EXCELENTE")
    else:
        print("REPROBADO")

    ¿Qué se imprime?
    a) Aprobado
    b) Excelente
    c) Reprobado
    d) Error de sintaxis (porque no hay 'else')

    **Respuesta correcta: a**

13.  
    numero = 10
    if numero % 2 == 0:
        print("Número par")
    elif numero % 2 != 0:
        print("Número impar")
    print("Fin del programa")

    ¿Qué se imprime exactamente?
    a) Número par
    b) Número par\nFin del programa
    c) Fin del programa\nNúmero par
    d) Solo "Fin del programa"

    **Respuesta correcta: b**

14.  
    fruta = "Manzana"
    if fruta == "Manzana":
        print("Es una Manzana")
    elif fruta == "Pera":
        print("Es una Pera")
    print("Salida:", fruta)

    ¿Qué se imprime?
    a) Es una Manzana\nSalida: Manzana
    b) Salida: Manzana\nEs una Manzana
    c) Solo "Salida: Manzana"
    d) Error de indentación

    **Respuesta correcta: a**

15.  
    edad = 20
    if edad >= 18 and edad <= 30:
        print("Jóvenes adultos")
    elif edad > 30:
        print("Adultos mayores")
    print("Bucle terminado")

    ¿Qué se imprime?
    a) Jóvenes adultos\nBucle terminado
    b) Bucle terminado\nJóvenes adultos
    c) Solo "Adultos mayores" (porque 20 > 30)
    d) Error de condición AND

    **Respuesta correcta: a**

16.  
    for i in range(5):
        print(i, end=" ")

    ¿Qué se imprime en una línea?
    a) 0 1 2 3 4
    b) 1 2 3 4 5
    c) 0 1 2 3
    d) Error de rango

    **Respuesta correcta: a**

17.  
    lista = ["A", "B", "C"]
    for item in lista:
        print(item.upper(), end="")
    print() # Salto de línea final

    ¿Qué se imprime?
    a) ABC\n (mayúsculas, con salto)
    b) abc\n (minúsculas)
    c) AB C\n (solo dos)
    d) Error porque upper() no existe en strings

    **Respuesta correcta: a**

    a) 1 2 3 4 5
    b) 0 1 2 3 4
    c) Error porque while no tiene condicional
    d) Solo "0 " (no entra al bucle)

    **Respuesta correcta: a**

31.  
    lista = ["A", "B", "C"]
    for i in range(len(lista)):
        print(f"{i}: {lista[i]}")

    ¿Qué se imprime?
    a) 0: A\n1: B\n2: C
    b) A\nB\nC
    c) Error porque no se puede usar 'range' con listas directamente

    **Respuesta correcta: a**

32.  
    for i in range(3):

    ¿Qué se imprime?
    a) 10 11 12
    b) 3 4 5
    c) 0 1 2
    d) Error porque 'i' no está definido correctamente

    **Respuesta correcta: a**

**PREGUNTAS DE TEMAS 0, 1 Y 2 (Errores comunes)**

36.  
    x = "hola"
    print(x * 2) # Multiplicación de string por entero

    ¿Qué se imprime?
    a) holahola
    b) Error porque no se puede multiplicar strings por enteros
    c) HolaHola (con mayúsculas)
    d) Solo "hola" (no se repite)

    **Respuesta correcta: a**

37.  
    lista = [1, 2, 3]
    print(lista[0] + lista[3]) # Acceso a índice fuera de rango

    ¿Qué se imprime?
    a) 4
    b) Error porque el índice 3 no existe en una lista de tamaño 3 (índices válidos: 0,1,2)
    c) 3 (porque Python ignora errores de índices en bucles)
    d) Solo "lista[0] + lista[3]" como texto

    **Respuesta correcta: b** (Se produce un IndexError).

38.  
    x = True
    print(x == True) # Comparación booleana directa

    ¿Qué se imprime?
    a) True
    b) False
    c) Error porque no se puede comparar booleanos con '='
    d) El texto "True" en mayúsculas

    **Respuesta correcta: a**

39.  
    x = 10
    print(x // x) # División entera de un número por sí mismo

    ¿Qué se imprime?
    a) 1.0 (porque en Python la división siempre devuelve flotante, pero // es entero)
    b) 1 (resultado entero exacto porque ambos son enteros)
    c) Error porque no se puede dividir por cero (no lo es)
    d) El texto "1"

    **Respuesta correcta: b**

40.  
    for i in range(5):
